# NAM to CLO v2.5.4 - Guarded VST Tail Tone Match

This branch keeps PRE, Block A, P/K and POST unchanged and modifies only the Ampero 2048-tap Block B.

## Tone-match source
- SOURCE: final 20 seconds rendered through the official converted CLO.
- TARGET: final 20 seconds of the NAM render generated by the converter.
- Analysis: SOURCE_latest_19 VST CAB Tone Match port, FFT 16384, Hann, 75% overlap, 11 median-of-means groups, 512 log-spaced comparison points.
- Smooth: 5% (about 1/120 octave).
- Solver: 2048-sample minimum-phase IR.

## v2.5.4 guards
1. Remove the weighted global dB correction offset.
2. Clamp trusted correction to +/-3 dB.
3. Ignore comparison bins with confidence below 0.20; confidence already includes frame count, spectral energy and stability.
4. Apply full correction through 6 kHz.
5. Raised-cosine fade from 6 to 8 kHz.
6. Exactly 0 dB correction above 8 kHz.
7. Single pass only; the v2.5.3 1-8 kHz residual second pass is removed.
